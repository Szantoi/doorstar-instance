Gomb az Üzemi Tábla ipari krómjához — outline a lap-műveletekhez, primary (kék) a kiadáshoz, chrome/active a felső menühöz, danger a visszavonáshoz.
```jsx
<Button variant="primary" onClick={issue}>Munkamenet kiadása</Button>
<Button>Betölt</Button>
```
Hover konvenció: outline gomb fehér→fekete invert.
